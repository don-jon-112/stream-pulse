Persyaratan Keamanan & Batasan Riset (Security Guidelines)

Platform riset ini dirancang hanya untuk pengujian internal pada server tes privat milik sendiri. Patuhi rambu-rambu berikut:

  • Hanya simulasikan traffic ke server tes privat terkontrol (loopback/internal test environment).
  • Dilarang keras mengotomatisasi sesi viewer langsung ke platform live Twitch resmi.
  • Dilarang keras mencoba membobol atau mengelabuhi sistem deteksi bot pihak ketiga.
  • Dilarang keras menggunakan jaringan residential proxy untuk memanipulasi jumlah viewership publik.
  • Wajib mengamankan API key dan kredensial server simulasi.
  • Wajib menerapkan autentikasi ketat untuk dashboard kontrol simulasi.
  • Terapkan batasan koneksi dan kuota resource VPS secara ketat agar server tidak crash.
  • Cegah endpoint stress-testing agar tidak dapat diakses secara publik tanpa token rahasia.

1. Ringkasan Proyek (Overview)

Membangun platform riset mandiri (self-hosted) yang mensimulasikan koneksi virtual viewer ke server tes streaming terkontrol milik pribadi.

Tujuan Riset:
  • Memahami cara kerja virtual client berskala besar.
  • Menganalisis komunikasi konkurensi tinggi via HTTP dan WebSocket.
  • Manajemen siklus hidup sesi (session lifecycle management).
  • Pola lalu lintas jaringan dan konsumsi sumber daya VPS (RAM, CPU, I/O).
  • Klasifikasi pola trafik dan deteksi anomali lonjakan (anomaly detection).
