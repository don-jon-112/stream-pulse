Cara Ambil Session ID (Hanya jika dibutuhkan):
1. Buka tiktok.com di browser PC dan pastikan sudah login akun TikTok Anda.
2. Tekan F12 (DevTools) → buka tab Application (Chrome/Edge) atau Penyimpanan / Storage (Firefox/Indo).
3. Di panel kiri, buka Kuki / Cookies → pilih https://www.tiktok.com.
4. Cari baris bernama sessionid, lalu salin nilainya dan tempel di kolom di atas.
💡 Cukup pasang sekali, berlaku berbulan-bulan selama Anda tidak klik Log out di browser.

Siap Digunakan di OBS Studio! 🎉

Salin tautan Browser Source di bawah dan tempelkan ke OBS Studio Anda.

💡 Cara Pasang di OBS Studio (Hanya 15 Detik):

1 Buka OBS Studio -> Di panel Sources, klik tanda + -> Pilih Browser.
2 Tempelkan URL di atas. Atur Width: 450 dan Height: 650.
3 Centang "Shutdown source when not visible", lalu klik OK. Chat sudah langsung live!
