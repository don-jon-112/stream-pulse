Kebijakan Privasi & Keamanan Data

StreamPulse berkomitmen untuk melindungi privasi Anda. Layanan kami dirancang untuk memantau chat dan mengelola OBS overlay tanpa melacak atau memperjualbelikan data pribadi Anda.

1. Data yang Kami Kumpulkan

  • Alamat Email: Digunakan secara eksklusif untuk verifikasi kepemilikan akun saat registrasi dan pemulihan akun. Kami tidak mengirimkan email spam atau buletin promosi.
  • Nama Pengguna (Username): Identitas akun Anda untuk mengelola konfigurasi saluran dan slot overlay.
  • Nama Saluran Publik: Nama channel Twitch, YouTube, dan TikTok yang Anda pilih untuk dipantau secara publik.
  • Token OAuth Twitch (Opsional): Digunakan untuk menangkap event interaktif (Channel Points Redeem). Token ini dienkripsi secara ketat menggunakan AES-256-GCM di server kami dan tidak pernah dibocorkan ke browser.
  • Kata Sandi: Dienkripsi menggunakan algoritma hashing memori keras mutakhir Argon2id dengan salt unik. Kami tidak dapat melihat kata sandi asli Anda.

2. Pemrosesan Data Chat & Live Stream

Pesan chat dari penonton Twitch, YouTube, dan TikTok diproses secara real-time streaming di perangkat/browser Anda menggunakan protokol WebSocket. StreamPulse tidak menyimpan riwayat isi chat penonton ke database permanen. Saat sesi streaming selesai atau browser ditutup, pesan chat langsung dibersihkan dari memori.

3. Penggunaan Cookie & Penyimpanan Lokal

Kami hanya menggunakan localStorage dan sessionStorage di browser Anda untuk menyimpan token sesi login Anda dan preferensi tampilan. Kami tidak menggunakan cookie pelacak pihak ketiga atau iklan (No Third-Party Trackers).

4. Keamanan & Enkripsi

Seluruh komunikasi data antara browser, OBS Studio, dan server kami dilindungi dengan enkripsi SSL/TLS (HTTPS & WSS). Kredensial sensitif disimpan terenkripsi dan terlindung dari akses tidak sah dengan mekanisme Rate Limiting.

Penghapusan Akun & Data (Data Deletion)

GDPR

Sesuai dengan hak privasi pengguna (GDPR Compliance), Anda berhak menghapus akun Anda kapan saja. Jika Anda menghapus akun, seluruh data profil Anda, kredensial yang tersimpan, dan slot OBS Overlay Anda akan dihapus secara permanen dari server dan tidak dapat dipulihkan kembali.

Akun Aktif: - (-)
Seluruh slot OBS overlay milik akun ini akan langsung dimusnahkan.

Anda sedang tidak login. Silakan Masuk ke Akun Anda terlebih dahulu untuk mengakses menu penghapusan akun mandiri.
