Cara Pasang di OBS Studio:
  1. Buka OBS Studio, klik tanda + pada panel Sources.
  2. Pilih Browser Source dan beri nama (misal: Stream Viewers).
  3. Paste URL di atas ke dalam kolom URL.
  4. Atur ukuran resolusi rekomendasi: Width: 500, Height: 140 (atau disesuaikan).
  5. Centang "Shutdown source when not visible" untuk hemat resource GPU streamer.
